# 项目问题与优化记录

项目从外部托管论坛逐步演进为自托管社区。以下内容根据 2026 年 9 月 2 日至 4 日的完整开发过程、验收记录和实际测试整理。

## 主要问题

| 问题 | 调整 | 结果 |
|---|---|---|
| 原论坛在外部平台，无法作为真正的内网论坛 | 在自己的服务器部署 Discourse | 数据和服务转到自己控制的环境 |
| 没有公网地址 | 使用域名和主动外连通道 | 内网和公网可同时访问 |
| 每次打开都要重新登录和选头像 | 增加一年登录状态、上次账号与头像记忆 | 常规重开无需再次填写 |
| 特殊姓名可直接进入管理后台 | 取消该入口，改为管理员账号和密码 | 管理权限不再依赖公开口令 |
| 邀请有效却无法注册 | 修正邀请与普通注册的设置冲突 | 有效邀请可以登记 |
| 公网仍要求邮箱激活 | 公网复用自定义实名登记流程 | 不需要邮箱激活 |
| 公网和内网数据是否同步不确定 | 做双向发帖、回复和聊天测试 | 双向读取正常 |
| 公网入口曾出现 1033 错误 | 定位为服务器外连通道问题并恢复 | 公网入口恢复；长期仍依赖稳定网络 |
| 登录页位置、警告和人物效果反复调整 | 先做预览，再调整居中、人物手部和提示文案 | 正式页面已更新 |
| 注册密码页面和后台限制可能不一致 | 统一为至少 8 位并修正错误提示 | 8 位规则生效 |
| 关键词过滤容易通过空格或变体绕过 | 增加模型审核、固定底线和人工待审 | 风险处理更完整 |
| 大模型导致内存不足 | 删除过重模型，改用轻量审核模型 | 论坛和审核可以同时运行 |
| 匿名社区容易发生骚扰 | 限定板块、管理员可追溯、私聊必须实名 | 匿名功能可控 |
| 缺少公开聊天助手 | 增加只在点名时回复的科仔 AI 助手 | 公网和内网均已验证 |
| 测试数据可能污染正式社区 | 测试后清理账号、消息和待审内容 | 正式区保持干净 |

## 仍然需要注意

- 公网入口不能依赖个人电脑长期在线；
- 内网应配置正式证书；
- 自行填写实名信息不等于证件核验；
- 轻量模型不能替代管理员；
- 需要补做独立备份和恢复演练；
- 应在实体安卓手机、iPhone 和鸿蒙设备上继续测试。
